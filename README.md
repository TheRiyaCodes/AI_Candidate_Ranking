# 🧠 AI Candidate Ranking Engine

## 📌 About
This project ranks job candidates based on Job Description (JD) using AI.

## 🚀 Features
- Upload Job Description
- Upload Candidate CSV
- AI-based ranking system
- Explainable results

## 🛠 Tech Stack
- Python
- Streamlit
- Pandas
- NumPy
- Sentence Transformers

## 🎯 Goal
To improve hiring process using AI ranking system.
